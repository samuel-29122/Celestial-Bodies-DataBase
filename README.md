# Celestial Bodies Database

## About This Project

This project was completed as part of the freeCodeCamp Relational Database course.

I used PostgreSQL and SQL to create a database containing information about celestial bodies.

## Database Structure

The database contains five tables:

- **Galaxy** – Information about galaxies.
- **Star** – Information about stars.
- **Planet** – Information about planets.
- **Moon** – Information about moons.
- **Comet** – Information about comets.

## Skills Practised

- PostgreSQL
- SQL commands
- Creating and managing databases
- Primary and foreign keys
- Database relationships
- Working with tables and data
